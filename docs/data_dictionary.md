# Data dictionary — planned indicators

| Indicator | Dutch term | Unit | Key limitation |
|---|---|---|---|
| Average sale price | Gemiddelde verkoopprijs | EUR per sold dwelling | Sales mix changes by year |
| House price index | Prijsindex bestaande koopwoningen | Index | Different from mean sale price |
| Household income | Inkomen huishoudens | EUR per household/year | Check income definition |
| Housing stock | Woningvoorraad | Dwellings | Ownership category matters |
| Corporation stock | Woningen woningcorporaties | Dwellings | Not synonymous with social rent |
| Rental price change | Huurprijsontwikkeling | Percent | Not monthly rental level |
| Building completions | Nieuwbouw / gereedgekomen woningen | Dwellings/year | Not permits |
| Demolition | Sloop | Dwellings/year | Check reporting scope |
| Housing permits | Bouwvergunningen | Dwellings/year | Not completions |
| Registrants | Ingeschreven woningzoekenden | Persons/households | System-specific denominator |
| Active seekers | Actief woningzoekenden | Persons/households | System-specific definition |
| Allocations | Verhuringen / toewijzingen | Dwellings/year | Check direct allocation coverage |
| Registration duration | Inschrijfduur | Years | Not prospective wait |
| Active search duration | Zoekduur | Years | Not same as inschrijfduur |
| Success probability | Slaagkans | Percent | Denominator must be verified |
| Lottery | Loting | Allocations | Method; may overlap recipient groups |
| Urgency | Urgentie | Allocations | Eligibility varies by region |
| Status holders | Statushouders | Allocations | Recipient category, not allocation method |
| Direct allocation | Directe bemiddeling | Allocations | Allocation method |
| Corporation sales | Verkoop corporatiewoningen | Dwellings/year | Verify sale-to-tenant detail |
| Mortgage interest | Hypotheekrente | Percent per year | Scenario only |

**Status:** proposed definitions. Source field names, units and geographic codes must be confirmed against raw files before analysis.
